# Sipher 0.3.0

Fabric, and Minecraft versions from 1.21 to 26.3.

## New

- **Fabric.** Sipher now runs on Fabric as well as NeoForge, with every feature: live captions, bubbles, the transcript, translation and language packs. On Fabric it needs Fabric API and Simple Voice Chat; with Mod Menu installed, Sipher's settings open from the mod list.
- **More Minecraft versions.** Fabric: 1.21–1.21.1, 1.21.4, 1.21.5, 1.21.6–1.21.8, 1.21.9–1.21.10, 1.21.11, 26.1–26.1.2, 26.2 and 26.3. NeoForge: 1.21.1, 1.21.4, 1.21.5, 1.21.8, 1.21.10, 1.21.11, 26.1.2, 26.2 and 26.3. Pick the file for your loader and Minecraft version.
- **Fabric and NeoForge players can play together.** On a Fabric or a NeoForge server, players on either loader see each other's captions.

## Fixes

- Sipher's own messages, such as "Sipher ready" and any errors, are back in the game log (`logs/latest.log`). They had been missing since 0.1.0, which made problems harder to track down.

## For mod developers

- `PlayerCaptionEvent` and `SipherCaptions.show` work the same on both loaders. On NeoForge the event is still posted on `NeoForge.EVENT_BUS`; on Fabric, register a listener on `PlayerCaptionEvent.EVENT`.

## Compatibility

- Clients and servers on 0.1.0, 0.2.0 and 0.3.0 can play together. On a Fabric server, NeoForge players need 0.3.0 to see other players' captions.
- Your settings carry over: `sipher-client.toml` and `sipher-server.toml` keep their format and keys.
- No changes to language packs: installed packs keep working and nothing new needs downloading.

Feedback and bug reports: https://github.com/Eiriksb/Sipher/issues (please include *Copy diagnostics*)
