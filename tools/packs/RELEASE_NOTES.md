Optional language packs for [Sipher](https://github.com/Eiriksb/Sipher). You do not need to download anything from
here: install a language from inside the game (Sipher settings → Languages…), which downloads exactly these files and
verifies each one against the SHA-256 checksum built into the mod.

Every file is model data (ONNX weights, tokenizer/vocabulary files, licences) — no code. Each component ships with its
`LICENSE` file naming the original model, its authors and licence (MIT, Apache-2.0, CC-BY-4.0, CC-BY-SA-4.0 for
Japanese translation, the NVIDIA Open Model License for Danish speech, and the FunASR Model License for SenseVoice).

How the files were produced: see `tools/packs/` in the repository.
